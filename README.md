# Shubham Agarwal Portfolio

This is a personal portfolio website built with React + Vite.

## Tech Stack
- **Framework**: React 19
- **Build Tool**: Vite 6
- **Styling**: Vanilla CSS with modern CSS Variables & Dark Theme

## Setup
1. Clone repository
2. Run `npm install`
3. Run `npm run dev` to start development server

## Design System
The project uses a custom design system with CSS variables defined in `src/index.css`.
- Colors: Indigo / Violet / Slate
- Font: Inter (Google Fonts)
